راهنمای ویرایش سایت انجمن
==========================

۱) جایگزین کردن سایت قبلی روی گیت‌هاب
   - وارد مخزن (repository) شو، Add file ← Upload files.
   - دو فایل index.html و logo.jpg را بکش و Commit changes بزن.
   - چون اسم فایل‌ها یکی است، نسخه‌ی قبلی جایگزین می‌شود. لینک و QR تغییری نمی‌کنند.
   - بعد از یک تا سه دقیقه صفحه به‌روز می‌شود. اگر قدیمی دیدی، رفرش سخت بزن.

۲) ویرایش متن‌ها
   - در مخزن روی index.html بزن، بعد آیکون مداد (Edit).
   - فقط بخش «تنظیمات صفحه» (CONFIG) را عوض کن. بقیه‌ی فایل را دست نزن.
   - پایین صفحه Commit changes بزن.

۳) افزودن عکس اعضا، کاور پادکست و جلد نشریه
   - Add file ← Upload files، و عکس را در پوشه‌ی images آپلود کن
     (برای ساخت پوشه: Add file ← Create new file، در کادر اسم بنویس images/test.txt و Commit بزن؛ بعد عکس‌ها را داخلش آپلود کن).
   - عکس‌ها را کوچک کن (حدود ۵۰۰ پیکسل) تا صفحه سریع باز شود.
   - اسم عکس را در CONFIG بنویس، مثلاً: photo: "images/ali.jpg"

۴) افزودن اپیزود یا شماره‌ی جدید
   - یک خط از لیست podcast یا newsletter را کپی کن و بالای همان لیست بگذار.
   - حواست به کاما (,) آخر هر خط باشد؛ خط آخر لیست کاما ندارد.

۵) فعال کردن دکمه‌ی عضویت
   - لینک ربات یا فرم را داخل joinUrl بگذار، مثلاً: joinUrl: "https://t.me/اسم_ربات"

۶) ویدئوی معرفی
   - لینک آپارات یا یوتیوب را داخل video بگذار، یا فایل mp4 را آپلود کن و اسمش را بنویس.

۷) ایتا و بله
   - در بخش links، مقدار text و url آن‌ها را پر کن.

۸) مورد‌های نمونه
   - اسم‌ها و سمت‌های اعضا، «اپیزود اول» و «شماره‌ی اول» نمونه هستند. حتماً قبل از انتشار واقعی با اطلاعات درست عوض یا حذف کن.
